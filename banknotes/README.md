# Paper Tender

Одностраничная витрина банкнот с горизонтальным 3D-рядом при вертикальном скролле.
Сделана на обычных HTML, CSS и JS без сборщика: Three.js 0.186.1, GSAP 3.15 + ScrollTrigger и Lenis 1.3.26 подключаются через importmap с jsDelivr.

```
npx serve banknotes
```

- `index.html`: разметка, importmap и список купюр. Этот список — единственный источник данных, его же видят скринридеры и браузеры без WebGL.
- `styles.css`: все цвета и размеры заданы в CSS-переменных в `:root`.
- `main.js`: сцена, скролл, подписи и прелоадер. Числовые настройки собраны в `CONFIG` в начале файла.
- `assets/objects/`: картинки купюр (01–05.png), `assets/noise.png` — текстура шума.
